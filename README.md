# Rabt · ربط

ملفات الموقع: dashboard.html (لوحة المتجر)، catalog.html (صفحة الزبون)، config.js (الإعدادات)، setup.sql (قاعدة البيانات).

## التشغيل لأول مرة
1. Supabase > SQL Editor > الصق محتوى setup.sql > Run.
2. Supabase > Authentication > Providers > Email: أطفئ "Confirm email" (حتى يدخل التاجر فوراً بدون رسالة تأكيد).
3. ارفع الملفات الأربعة إلى GitHub وفعّل Pages (أو Vercel).
4. افتح dashboard.html من الرابط العام وأنشئ أول متجر.

رابط كل متجر: .../catalog.html?s=اسم-الرابط
